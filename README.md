# Titanic Survival Prediction

Jupyter notebook project exploring passenger-survival prediction with the Titanic dataset. The repository includes `titanic.ipynb` and the `train.csv` and `test.csv` data files.

Open the notebook in Jupyter and run its cells in order. Install the libraries imported by the notebook in your environment first. The repository name's accuracy figure is not independently verified here; treat model performance as dependent on the notebook's validation method and data split.
